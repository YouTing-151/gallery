# Gallery · 博主作品画廊

单博主个人画廊站点：作品 / 合集展示、点赞收藏评论、小店商品与订单，支持博主、管理员、客服、普通用户四类角色。

## 技术栈

- 后端：Java 17、Spring Boot 3.4.4、MyBatis、MySQL 8、Maven、Lombok、BCrypt 密码加密
- 前端：待开发（`gallery-frontend/`）

## 目录结构

```
gallery/
├── gallery-backend/            后端 Spring Boot 工程
│   ├── sql/                    建表脚本 schema.sql 与种子数据 data.sql
│   └── src/main/java/com/gallery/gallerybackend/
│       ├── common/             统一返回 Result、业务异常、全局异常、角色常量
│       ├── controller/         接口层
│       ├── service/            业务层（接口 + impl）
│       ├── mapper/             MyBatis 数据访问层
│       ├── entity/             数据库实体类
│       ├── dto/                请求 / 响应对象
│       └── util/               工具类（密码加密）
└── gallery-frontend/           前端工程（待开发）
```

## 数据库

- 库名：`gallery_db`，本地连接 `localhost:3306`，账号 `root` / 密码 `123456`
- 初始化顺序：先执行 `sql/schema.sql` 建库建表，再执行 `sql/data.sql` 写入演示数据

## 本地运行

- 环境：JDK 17、MySQL 8、Maven Wrapper（无需单独安装 Maven）
- 后端：进入 `gallery-backend/`，执行 `./mvnw spring-boot:run`，端口 `8080`

## 角色约定

| 角色 | 标识 | 权限范围 |
|---|---|---|
| blogger | 博主 | 主页、合集、作品、商品全部管理权限 |
| admin | 管理员 | 删评论、发布通知、拉黑用户、调整权限 |
| service | 客服 | 回复商品咨询、管理库存与价格 |
| user | 普通用户 | 浏览、点赞、收藏、评论、下单、打赏 |
